Seat Saver — License Waste Report for Jira

Atlassian bills per user, every month. People leave, switch teams, or stop using Jira — and their seats keep billing. Seat Saver puts the number on the screen in the first minute.

What it does

  • Lists every user holding a paid Jira application role.
  • Finds each user's most recent Jira work activity (assignee, reporter, creator or logged work).
  • Flags users idle beyond your threshold and prices them with your per-seat cost.
  • Flags likely service accounts; lets you ignore accounts you'd never reclaim.
  • Keeps a monthly history so you can show waste going down. Exports CSV.

What it never does

Deactivate users, change groups or licenses, or send data outside Atlassian. It is read-only and runs entirely on Atlassian infrastructure.

How idleness is measured

Jira Cloud does not expose last-login to any Marketplace app. Seat Saver uses last work activity. Someone who only reads boards will look idle — treat the list as a shortlist to verify, not a verdict.

Setup

  1. Install from the Atlassian Marketplace (requires Jira admin).
  2. Open Jira settings → Apps → Seat Saver.
  3. Click Run first scan. About a minute per 500 users.
  4. In Settings, enter what you pay per user per month so costs are exact.
